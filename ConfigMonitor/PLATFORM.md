# اتصال خودکار برنامه به پنل

از نسخهٔ 2.0.0-beta4، آدرس https://panel.configmonitor.top ثابت است و اتصال هنگام شروع برنامه خودکار فعال می‌شود. تنظیم اتصال، فرم تأیید و قطع اتصال داخل برنامه وجود ندارند. توضیح اطلاعات ارسالی در «دربارهٔ ما» نمایش داده می‌شود: شناسهٔ تصادفی نصب، مدل گوشی، نسخه‌های اندروید و برنامه، آخرین حضور و آمار تبلیغ. کشور و شهر از IP تخمین زده می‌شوند؛ کانفیگ‌ها و کلیدهایشان ارسال نمی‌شوند.

شناسهٔ موجود برای همین دامنه حفظ می‌شود؛ نصب تازه، قبلاً قطع‌شده یا متصل به دامنهٔ دیگری برای دامنهٔ رسمی آماده می‌شود. مشخصات ذخیره‌شدهٔ پایش دست‌نخورده می‌ماند. خطای شبکه اتصال را غیرفعال نمی‌کند؛ بررسی بعدی تلاش مجدد دارد. در پس‌زمینه، زمان‌بندی تابع محدودیت‌های اندروید است و دریافت لحظه‌ای تضمین نمی‌شود.

دامنه در app/src/main/assets/platform.json قرار دارد. بستهٔ سرور Config-Monitor-Platform-2.0.0-beta1.zip و API آن تغییر نکرده‌اند؛ فیلد قدیمی consent در درخواست ثبت برای سازگاری API باقی مانده است. نصب سرور و HTTPS معتبر لازم است. کلید امضا داخل سورس نیست. جزئیات آزمون‌ها در VALIDATION.md آمده است.
