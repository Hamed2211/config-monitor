# به‌روزرسانی Config Monitor ۲.۲.۱

نسخهٔ پایدار، کد نسخهٔ ۲۱، با همان امضای نسخهٔ قبلی. فایل APK را روی نسخهٔ فعلی نصب کن؛ حذف برنامه لازم نیست.

## کشورِ خروجی کانفیگ

- درخواست HTTPS به سرویس ipify فقط از داخل همان کانفیگ ارسال می‌شود. IP عمومی‌ای که مقصد بعد از عبور از تونل‌ها می‌بیند ثبت می‌شود؛ کشور آن از دیتابیس DB-IP همراه برنامه به‌صورت محلی خوانده می‌شود.
- دامنه یا IP ورودی کانفیگ برای تعیین کشور کانفیگ استفاده نمی‌شود. دو کانفیگ با دامنهٔ یکسان می‌توانند خروجی و کشور متفاوتی داشته باشند.
- کشور و پرچم کنار وضعیت کارت و در صفحهٔ مدیریت نمایش داده می‌شوند. در مدیریت، IP خروجی، زمان آخرین بررسی و دکمهٔ «بررسی دوبارهٔ خروجی» اضافه شده‌اند.
- اولین بررسی خودکار بعد از یک تست اتصال موفق انجام می‌شود. پس از نتیجهٔ موفق، فاصلهٔ بررسی خروجی ۱۰ دقیقه است؛ پس از خطا، تلاش بعدی با اولین تست موفق پس از ۲ دقیقه انجام می‌شود. بررسی دستی هم موجود است.
- شکست تشخیص خروجی، نتیجهٔ پینگ یا شمارندهٔ هشدار را تغییر نمی‌دهد. نتیجهٔ قبلی با برچسب «آخرین خروجی» می‌ماند؛ اگر نتیجه‌ای نداریم کشور نامشخص است. هیچ برگشتی به کشور IP ورودی یا اینترنت مستقیم گوشی وجود ندارد.
- برای آدرس‌ها و سرورهای مستقیم، کشور همچنان به IP همان مقصد مربوط است.

IP نمایش‌داده‌شده، خروجی مسیر درخواست به ipify است. اگر سرور بر اساس مقصد، IPv4/IPv6 یا مسیر ترافیک خروجی‌های متفاوتی داشته باشد، لزوماً یک IP برای همهٔ مقصدها ندارد. موقعیت DB-IP تقریبی است. سرویس ipify IP خروجی درخواست را می‌بیند؛ کانفیگ، کلید خصوصی و نام کانفیگ برای آن فرستاده نمی‌شوند. مرجع: https://www.ipify.org

## سایت

بخش «همهٔ امکانات، یک‌جا» در ۸ دسته با فارسی و انگلیسی، تم روشن/تیره و چیدمان موبایل اضافه شده است. نسخه، توضیح روش تشخیص خروجی، فایل‌های دانلود و هش‌ها به ۲.۲.۱ به‌روزرسانی شده‌اند.

محتوای Config-Monitor-Website-2.2.1.zip را در ریشهٔ سایت جایگزین کن؛ پوشهٔ downloads هم لازم است. این بسته فایل‌های APK امضاشده را در قطعه‌های قابل دانلود مرورگر ارائه می‌کند. فایل HTML پیش‌نمایش فقط برای مرور طراحی و داده‌های نمونه است. سایت روی هاست شما منتشر نشده و پنل سرور نیاز به تغییر ندارد.

## بررسی انجام‌شده

۱۲۰ تست JVM شامل مسیر SOCKS احراز هویت‌شده، خروجی مستقل Xray/sing-box بدون مسیر مستقیم، رد IP خصوصی/نام دامنه/پاسخ HTTP نامعتبر، جدایی کشور ورودی از خروجی و تست‌های قبلی هشدار موفق شدند. ۱۳ مجموعهٔ تست DOM برنامه برای دو زبان و دو تم موفق شدند. تست‌های سایت شامل ترجمهٔ کامل، تعامل‌ها، لینک‌ها و صحت SHA-256 دانلودها اجرا شده‌اند. امضا، نسخه، DEX تازه، همهٔ فایل‌های رابط، دیتابیس کشور و کتابخانه‌های هر دو APK بررسی شده‌اند.

آزمایش واقعی روی گوشی و یک کانفیگ دو‌سرورهٔ شما انجام نشده است. مرور تصویری داخل مرورگر نیز انجام نشده؛ بررسی رابط با DOM و منابع تولیدشده است. برای کنترل روی گوشی: کانفیگ را روشن کن، صفحهٔ مدیریت را باز کن و «بررسی دوبارهٔ خروجی» را بزن؛ مقدار را با IP عمومی مشاهده‌شده هنگام استفاده از همان کانفیگ مقایسه کن. اگر ipify در مسیر کانفیگ مسدود باشد، کشور نامشخص/آخرین نتیجه خواهد بود.
