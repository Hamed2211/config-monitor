# Config Monitor 2.0.0-beta5

نسخهٔ ۲.۰.۰ بتا ۵ با کد ۱۷ و همان امضای قبلی آماده شده است؛ روی نسخهٔ نصب‌شده به‌روزرسانی کن و برنامه را حذف نکن.

اصلاح اصلی: تأیید قبلی «متوجه شدم» دیگر قطعیِ ادامه‌دار را پس از بازشدن دوبارهٔ برنامه یا شروع دوبارهٔ پایش بی‌صدا نگه نمی‌دارد. برنامه یک بررسی تازه انجام می‌دهد؛ اگر قطعی ادامه داشته و آستانهٔ خطا تکمیل شده باشد، هشدار دوباره فعال می‌شود. اگر در فاصلهٔ بسته‌بودن وصل شده باشد، بر اساس وضعیت قدیمی زنگ نمی‌زند.

کانفیگی که از ابتدای اجرا قطع است نیز بدون نیاز به یک‌بار وصل‌شدن هشدار می‌دهد. شمارندهٔ خطا با بازکردن دوباره صفر نمی‌شود. آستانهٔ تنظیم‌شده، پیش‌فرض شش خطای پیاپی، همچنان رعایت می‌شود.

«متوجه شدم» زنگ همان نشست را خاموش می‌کند؛ بازگشت از صفحهٔ هشدار به صفحهٔ اصلی به‌تنهایی دوباره زنگ ایجاد نمی‌کند. خروج کامل از محیط برنامه و بازگشت، نشست تازه محسوب می‌شود. تعویق، نگهداری، کانفیگ غیرفعال و توقف دستی پایش حفظ شده‌اند. اتصال خودکار پنل و سایر اصلاحات نسخهٔ قبل نیز باقی هستند.

۹۴ تست منطقی و ۱۱ مجموعه تست رابط گذشتند. APK، امضا و پذیرش آپدیت در API محلی بررسی شدند. آزمایش روی گوشی واقعی انجام نشده است. پس از نصب، یک قطعی را تأیید کن، از برنامه خارج شو و دوباره باز کن تا مسیر کامل بررسی و زنگ روی گوشی خودت تأیید شود. پایش باید فعال باشد.
