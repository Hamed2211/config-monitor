# Visual reference and implementation

proposed-1.7.png is the previously shown concept. The production HTML/CSS now implements its compact dashboard, large latency hierarchy, grouped settings and chart-first report. Configuration/address categories, fallback tools, real permission status, save actions and reporting coverage remain functional. Sample counts and fabricated text from the conceptual image are not production data. To regenerate a static preview with sample data, run node tests/ui/create-design-preview.cjs after installing tests/ui dependencies.
