# Config Monitor 2.0.0-beta6

نسخهٔ ۲.۰.۰ بتا ۶ با کد ۱۸ و همان امضای قبلی ساخته شده است؛ روی نسخهٔ فعلی نصب کن و برنامه را حذف نکن.

- «متوجه شدم» فقط زنگ جاری مانیتور را قطع می‌کند.
- اگر اولین بررسی تازه بعدی همچنان قطعی را تأیید کند، زنگ دوباره فعال می‌شود؛ نیازی به بازکردن برنامه نیست.
- برای قطعیِ ازقبل‌تأییدشده، شمارندهٔ خطا از صفر شروع نمی‌شود و شش خطای دیگر لازم نیست. هشدار اولیه همچنان مطابق آستانهٔ تنظیمات است.
- اگر کانفیگ وصل شده باشد، هشدار تکرار نمی‌شود. تا وقتی زنگ فعلی فعال است نیز هر بررسی زنگ جداگانه‌ای ایجاد نمی‌کند.
- برای بی‌صدا ماندن طولانی‌تر از «تعویق ۱۵ دقیقه» استفاده کن. نگهداری، غیرفعال‌کردن مانیتور و توقف دستی پایش همچنان رعایت می‌شوند.
- متن راهنمای صفحهٔ هشدار برای توضیح این رفتار به‌روز شده است. اتصال خودکار پنل و اصلاحات قبلی حفظ شده‌اند.

تکرار زنگ به تکمیل بررسی بعدی بستگی دارد؛ فاصلهٔ پیش‌فرض پایش ۲۰ ثانیه است، اما زمان تست شبکه و محدودیت‌های گوشی می‌توانند آن را عقب بیندازند. بررسی‌ای که از قبل در حال اجرا بوده ممکن است کمی پس از زدن دکمه تمام شود.

۱۰۰ تست منطقی و ۱۱ مجموعه تست رابط گذشتند. امضا، محتوای APK و پذیرش آپدیت در API محلی بررسی شدند. تست صدا روی گوشی واقعی هنوز انجام نشده: با پایش روشن، یک هشدار را تأیید کن و برنامه را در پس‌زمینه نگه دار؛ اگر قطعی ادامه دارد، بررسی ناموفق بعدی باید دوباره زنگ را فعال کند.
